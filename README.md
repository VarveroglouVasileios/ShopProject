# Eleon Pantry · demo concept

Demo για επιδείξεις σε πελάτες: φανταστικό **e-shop με τοπικά προϊόντα της Θάσου**. Δεν είναι πραγματική επιχείρηση και οι παραγγελίες δεν στέλνονται πουθενά.

Live: https://varveroglouvasileios.github.io/ShopProject/

## Τι δείχνει
- Κατάλογος με μεγέθη και **πραγματικό απόθεμα** (εξαντλήθηκε, τελευταία τεμάχια). Το καλάθι δεν ξεπερνά ποτέ το απόθεμα.
- Καλάθι και ταμείο με επικύρωση πεδίων, περιοχές αποστολής (ηπειρωτική, νησιά, εξωτερικό), **δωρεάν αποστολή από 40 €**, κωδικός έκπτωσης (δοκιμάστε `THASOS10`, ισχύει από 20 €) και συσκευασία δώρου. Οι υπολογισμοί γίνονται σε λεπτά, χωρίς λάθη στρογγυλοποίησης.
- Επιβεβαίωση παραγγελίας με κωδικό και έλεγχο αποθέματος κατά την αποστολή.
- Διαχείριση παραγγελιών (`#/admin`, κωδικός `demo`): νέα → συσκευάστηκε → στάλθηκε. Η ακύρωση επιστρέφει τα τεμάχια στο απόθεμα.

## Τεχνολογία
Vue 3, TypeScript, Tailwind, vue-router (hash history για GitHub Pages), Vitest. Η λογική (καλάθι, απόθεμα, έκπτωση, αποστολή, επικύρωση) είναι καθαρές συναρτήσεις στο `src/lib/cart.ts` με tests. Τα δεδομένα μένουν στο `localStorage` και η διαχείριση έχει «Επαναφορά demo».

```bash
yarn install
yarn dev     # τοπικά
yarn test    # tests λογικής
yarn build   # production build
```

Οι φωτογραφίες είναι δημιουργημένες με AI και ενδεικτικές. Σχεδιασμός και υλοποίηση: Βασίλειος Βαρβέρογλου.
